# IDM Stock Transformation Refactor — Summary of Changes

**Date**: 2026-06-29
**Status**: ✅ Complete

---

## Overview
Fixed grade company hierarchy for ManajemenIDM (regrading) to ensure IDM output stock is tracked at parent level, not at input child grade level.

---

## Changes Made

### 1. Database Seeders

**`database/seeders/GradeCompanySeeder.php`**
- Added standalone `GradeCompany "IDM"` (no parent) for parent-level output tracking
- Kept `IDM A` and `IDM B` as children of `ParentGradeCompany "IDM"` for input categorization
- Output bins (`PERUTAN`, `KAKIAN`, `ALU/AFKIR`) remain standalone

**Grade Hierarchy After Fix:**
```
ParentGradeCompany "IDM"
  ├── GradeCompany "IDM A" (input category)
  └── GradeCompany "IDM B" (input category)

GradeCompany "IDM" (standalone — output tracking)
GradeCompany "PERUTAN" (standalone)
GradeCompany "KAKIAN" (standalone)
GradeCompany "ALU/AFKIR" (standalone)
```

### 2. Service Logic

**`app/Services/Idm/ManajemenIdmService.php`**
- Updated `buildOutputs()` method:
  - **Before**: IDM output used input grade (`$sourceGradeCompanyId` = IDM A or IDM B)
  - **After**: IDM output now uses standalone "IDM" `GradeCompany`
  - KAKIAN, PERUTAN, ALU continue to use standalone grades resolved by name

**Impact on Inventory Transactions:**
```
IDM_REGRADING_OUT:  -1000g [IDM A/B]        (input deduksi — unchanged)
IDM_REGRADING_IN:   +700g  [IDM] ← CHANGED  (output now uses parent "IDM" grade)
IDM_REGRADING_IN:   +100g  [KAKIAN]         (byproduct — unchanged)
IDM_REGRADING_IN:   +150g  [PERUTAN]        (byproduct — unchanged)
IDM_REGRADING_IN:   +50g   [ALU]            (byproduct — unchanged)
```

### 3. Views (No Changes Needed)
- `resources/views/admin/manajemen-idm/step2.blade.php`
- `resources/views/admin/manajemen-idm/edit.blade.php`
- `resources/views/admin/manajemen-idm/show.blade.php`

All views already display the input grade as read-only ("Otomatis dari hasil grading"). No UI changes required.

### 4. Migrations (Already in Place)

## Stock Tracking Impact

**Before**: IDM output stock tracked at child grade level (IDM A/B)
**After**: IDM output stock tracked at parent-level standalone "IDM" grade

This aligns with the design principle: IDM output should roll up to parent level for tracking, while input categorization (IDM A/B) is separate concern during grading.
